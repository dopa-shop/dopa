# dopa

3DCGの商品がくるくる回る、**架空の**ショッピングアプリ（iPhone向けWebアプリ / PWA）。
お金は一切かからず、「買う」「届く」「開ける」の気持ちよさだけを味わえます。

## 遊び方（iPhone）

1. このリポジトリを静的ホスティングで公開する（例: GitHub Pages → Settings › Pages › Deploy from a branch）
2. iPhoneの Safari で公開URLを開く
3. 共有ボタン › **ホーム画面に追加** → アイコンから全画面アプリとして起動

ローカル確認だけなら:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

ビルド手順はありません。`index.html` をそのまま配信すれば動きます。

## 中身

- **150商品 × 11カテゴリ**: 食品・飲料 / ファッション / コスメ・美容 / ドラッグストア / インテリア / 家電・ガジェット / 日用品 / ホビー・スポーツ / ペット用品 / ベビー・キッズ / 文具・本
- **すべての商品はコードで作った3Dモデル**（画像素材ゼロ）。ガラス・ゼリー・メタル・布などの質感をPBRマテリアルで表現
- 商品ごとにカラーバリエーションがあり、選ぶと3Dモデルがその場で色替え

## シチュエーション爆買い

ホームの「シチュエーション爆買い」からスタートすると、20種類のお題からルーレットで1つが選ばれ、
相手からチャットでメッセージが届きます（「今からピクニックしない？」「別に怒ってないけど。」など）。
あとはお題にそって、予算を気にせず好きなだけカートへ。スライドで購入すると相手から返信が届き、買ったものがずらっと並びます。

- **採点やランク付けはありません。** 何を選んでも正解です
- 挑戦中はタブバーの上にお題・点数・金額が表示され、5点/10点/20点…や5万円/10万円…を超えるたびにお祝い
- 遊んだお題はマイページの「シチュエーション手帳」にスタンプとして残り、いつでも見返せます
- お題の購入ではガチャチケットが2枚もらえます

お題の追加・編集は `js/situations.js` で行えます。

## ドーパミン設計

| 瞬間 | 仕掛け |
| --- | --- |
| 商品を見る | 指でぐるっと回せる3D、タップすると「ぷにっ」とバウンド |
| カートに入れる | 商品がタブまで飛んでいく、効果音、触覚フィードバック |
| 送料無料ライン | 進捗バー → 到達した瞬間に紙吹雪 |
| 注文 | スライドして確定 → チェックマーク、ファンファーレ、獲得ポイントのカウントアップ |
| 会員ランク | ブロンズ → シルバー → ゴールド → プラチナ → ダイヤモンド。上がるとランクアップ演出 |
| 配送 | 「ドーパ便」で約40秒後にお届け。トラックが進むのをライブで追える |
| 開封 | 段ボールを3回タップして開封、中身がポンポン飛び出してコレクションに |
| ガチャ | 毎日1枚＋注文ごとに1枚のチケット。カプセルが割れてクーポンやポイントが当たる |
| バッジ | 「はじめての注文」「全カテゴリ制覇」など12種 |

効果音は Web Audio でその場で合成しています（音声ファイルなし）。iPhoneの消音モード中は鳴りません。
触覚フィードバックは iOS 18 以降の Safari で動作します。

## ファイル構成

```
index.html            エントリ（PWAメタ情報）
app.css               UI（ライト/ダーク対応）
js/main.js            画面・操作・演出
js/models.js          3Dモデル（全商品の手続き的モデリング）
js/render3d.js        3Dスタジオ（サムネイル生成・ライブビュー）
js/catalog.js         商品データ
js/situations.js      シチュエーション爆買いのお題（20種）
js/store.js           カート・注文・ランク・ガチャ・バッジ（localStorage保存）
js/fx.js              効果音・触覚・紙吹雪・アニメーション
vendor/               three.js r180（MITライセンス）
sw.js                 オフラインキャッシュ
dev/sheet.html        全3Dモデルの一覧（モデル調整用）
dev/icon.html         アプリアイコンのレンダリング
```

データはその端末の localStorage にだけ保存されます。登場する商品・ブランドはすべてフィクションです。
